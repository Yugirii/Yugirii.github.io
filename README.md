# Marcus Portfolio

Personal portfolio website built with Next.js and exported as a static site for
GitHub Pages.

## Local Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site locally.

## Deployment

The site is deployed through GitHub Actions from `.github/workflows/pages.yml`.
GitHub Pages must be configured with:

```text
Settings -> Pages -> Build and deployment -> Source -> GitHub Actions
```

The live site should publish to:

```text
https://yugirii.github.io/
```
